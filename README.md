# Site de l'Institut Sacré Cœur d'Adjamé

Collège et lycée catholique d'Adjamé, Abidjan — fondé en 1961.

**Le site en ligne : https://buildcoden.github.io/isca-adjame/**

## Ce dépôt

Il contient uniquement les fichiers servis au public : les neuf pages,
les feuilles de style, les scripts, les images et les trois documents
proposés au téléchargement (fiche de renseignements, fiches de
transport, règlement intérieur).

Les sources de travail — sauvegardes datées, fichiers d'origine en
pleine définition, documents internes, outils d'entretien — vivent dans
le dépôt privé `college-isca-adjame` et ne sont pas publiées ici.

## À savoir

L'Espace Enseignant et l'accès parent de la rubrique Paiement
s'adressent à une API qui n'est pas déployée : sur cette version en
ligne, la connexion ne peut pas aboutir. Tout le reste du site est
consultable.

## Mise à jour

Ce dépôt est régénéré depuis le dépôt de travail par
`outils/preparer-publication.py`, qui n'y recopie que ce que les pages
référencent réellement.
